# Visual reference — UniFi Network controller

Screenshots of the Ubiquiti UniFi Network controller (`unifi.ui.com`), kept as the
aesthetic and interaction reference for **Phase 12A — Visual Design System** in
`ROLLOUT_PLAN.md`.

| File                               | Pattern it illustrates                                                                                             |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| `unifi-site-manager-grid.png`      | Entity card grid, 24h activity strips with a "Now" marker, facet filter sidebar, global advisory banner, icon rail |
| `unifi-device-table.png`           | Dense sortable data table, status dot column, grouped checkbox filters with counts, column customization           |
| `unifi-port-detail-split-view.png` | Detail split view: properties panel, live timeline scrubber, topology map with per-node metrics, table below       |

These are reference only, for layout density and interaction patterns. Plenipo's
domain is agent workforce operations, not network monitoring. Do not copy UniFi
iconography, logos, or other proprietary assets.
