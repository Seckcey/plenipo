# v1.28.0 — Pick your GitHub repositories from a list

**This release turns the GitHub connection on. When you set up a project, you can now pick its
repository from a list of your own.** Plenipo by **8 West Ventures, LLC**.

## Highlights

- **Sign in with GitHub, then pick from a list.** In Settings → Connections, press **Sign in with
  GitHub**. Plenipo shows a short code and opens GitHub's own page. Type the code there, and
  that's it. No password goes into Plenipo. The sign-in is **read only** and **free**: Plenipo
  sees the names and descriptions of your repositories and who works on them, and never your code.
  No worker ever uses it.
- **A repository list on every project.** In **New project**, **Edit project**, and **Set up a
  Development project**, the repository box searches your repositories, your organizations' too,
  with private ones marked. Typing or pasting any address still works.
- **Where a project's files go.** The project dialog asks **Where its files go**: make a folder in
  the organization folder (the default), or use a folder you already have.
- **Work goes in its place.** In an organization folder, work that belongs to no project goes in
  the worker's own scratch pad. A project with no folder of its own keeps its work in its Files
  folder. The Files tab marks the files being changed.
- **Clearer chats between agents.** Each step of a worker's chat says what started it, such as
  "continued with handoff replies" or "checked in on its team". "From its lead" is shown for each
  message, not once for the whole chat.

## Fixed

- If a project's Files folder cannot be used, the worker's note now says why, instead of saying
  the project has no folder.

## For you, the owner

- Install this update on your PC. Plenipo offers it by itself (it checks GitHub once a day), or
  you can download it from this release.
- To use the list, open Settings → Connections → **GitHub**, sign in, and choose on GitHub which
  accounts Plenipo may list. If a repository is missing, use **Not here? Add an account or
  organization on GitHub**, then **Look again**.

## Good to know

- The decisions are [ADR-204](../adr/ADR-204-a-read-only-github-connection.md) (a read-only
  GitHub connection), [ADR-205](../adr/ADR-205-the-organization-folder.md) (the organization
  folder), and [ADR-208](../adr/ADR-208-talking-to-an-agent-is-direct.md) (talking to an agent is
  direct); the owner accepted all three on 2026-10-06.
- Making a copy of a repository on your PC comes in a later release.
