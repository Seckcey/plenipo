# v1.2.0 — Ollama's cloud models join the AI tools

Plenipo can now run tasks on **Ollama's cloud models**, next to Claude Code, Codex, and Grok.
The models run on Ollama's servers under your ollama.com sign-in, so no graphics card and no
API key are needed.

## Highlights

- **Ollama as an AI tool.** Install Ollama, run `ollama signin` once, and the **AI tools** card
  says **Ready** with "Ollama sign-in (free plan)". Pick **Ollama** in **Workers**, for a
  position, or in a role's model choices.
- **Your cloud models.** gpt-oss 120B (thinking low, medium, high) and Nemotron 3 Ultra work on
  the free plan. Kimi K3, DeepSeek V4 Pro, DeepSeek V4.1 Flash, GLM-5.3, GLM-5.3 Flash, and
  MiniMax M3 are listed as "(paid plan)": a task on one ends with "This model needs a paid
  Ollama plan". Plenipo never changes your plan.
- **Follow-ups remember.** Ollama keeps no conversations, so Plenipo keeps each one and sends it
  with every task.
- **Clear messages.** Not signed in, Ollama not running, a usage limit, or a paid-plan model each
  say what to do, never a raw error.

## Before you start

- Install Ollama from ollama.com/download, keep it running (its tray icon), and run
  `ollama signin`. Pull a cloud model once with `ollama pull gpt-oss:120b-cloud`.

## Known limits

- **Conversation only.** Ollama workers answer, write, and review text; they cannot read files
  or run programs yet. Giving them Plenipo's tools, checked by Guard, is a follow-up.
- Only cloud models are used; models on your own PC can be allowed later.

## Under the hood

- Plenipo talks to the Ollama service on `127.0.0.1:11434` only, through a helper mode of
  Plenipo itself, so each task keeps its time limit, Cancel, and records. It ignores
  `OLLAMA_HOST`, never uses an Ollama API key, and never keeps your email or name.

## Install

Download `Plenipo_1.2.0_x64-setup.exe` below and run it. It is a per-user install with no admin
rights needed. The installer is not code-signed yet, so Windows SmartScreen may warn: choose
**More info → Run anyway**. No Ledger upgrade is needed.
