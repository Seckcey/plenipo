# v0.6.0 — Your AI organization (Phase 5)

Plenipo now runs an organization, not just single workers. Build departments and projects on a
live map, hire a team under each supervisor, and give a supervisor an objective. It hands tasks
to its team, each worker shows up on the map while it works and leaves when it's done, and every
step is recorded.

## Highlights

- **The organization map.** A live map modelled on the UniFi Network topology page: you and your
  organization on the left, each team on its own line, with labels for the department, the
  project, and each worker's AI tool. Zoom, **Fit**, a minimap, and a "−" toggle to fold a team.
- **Build it by dragging.** Create a department (it comes with its manager) and a project (it
  comes with its supervisor). Drag a role from the **Hire** list onto a lead to hire. Drag a
  position onto another to change who it reports to, or to make it a team's reviewer, QA
  evaluator, or security auditor. Everything you can drag also works from the details panel with
  the keyboard, and the **List** view lets you filter and search.
- **Objectives.** Select a supervisor and give it an objective. It hands tasks to its team by job
  title ("Senior Developer", "Code Reviewer"). A worker is brought in for each task, appears
  under its position while it works, and leaves when done. Its history stays: **Former agents**,
  **Work → Recent**, and the full trail in **Activity**.
- **Plain words.** Every screen now uses everyday words: "AI tool" instead of runtime,
  "full-time" and "on call", "conversation" and "task". The chain of command reads Worker →
  Supervisor → Manager → VP → President (you).
- **Titles.** **Settings → Personalization → Titles** renames the ranks after the U.S. Army,
  Navy, Air Force, Marine Corps, Coast Guard, or Space Force, or the Mafia. It only changes what
  you see: job titles stay as you wrote them, and your AI agents are always given the plain
  titles.

## Fixes

- Codex errors read as a plain sentence instead of raw code — for example when Codex's own
  settings name a model your ChatGPT sign-in can't use.
- Quitting Plenipo always records the programs it stopped, even if the window closes first.
  Before, such a program could show as "interrupted" after the next start.
- Cancelling a task at the very moment it starts waiting for replies is no longer lost.

## Known issue

- A team task can take much longer than it should: agents write long messages to each other,
  and each reply carries the whole conversation forward. The next update (v0.6.1) keeps
  messages between agents short.

## Safety

- **Teams only.** A member of your organization can hand work only to its own team: the workers
  who report to it and anyone assigned to oversee it. Requests for anyone else, direct AI tool
  addresses, and AI tools the project doesn't allow are refused, and the requester is told why.
- **The rules are checked when a change is saved.** No loops in who reports to whom, only
  full-time positions lead a team, job titles are unique within a team, and nothing is left
  without a lead. Every change to the organization is recorded in the Ledger.
- **No new permissions.** Workers still can't change files: Claude Code workers get no tools and
  Codex workers run read-only without internet access. Permission to do more arrives with
  Plenipo Guard (Phase 7).
- **Titles are for show.** Military title sets use rank names only — no insignia, seals, or
  logos — and the Mafia set is never the default. No persona reaches your AI agents.

## Install

Download `Plenipo_0.6.0_x64-setup.exe` below and run it. It is a per-user install with no admin
rights needed. The installer is not code-signed yet, so Windows SmartScreen may warn: choose
**More info → Run anyway**.

Your existing Ledger is upgraded automatically (to schema version 4), after a verified backup of
the previous version in the Ledger's `backups` folder. After the upgrade, earlier versions of
Plenipo cannot open the Ledger.

Teams run on your own signed-in Claude Code and Codex (see the
[setup guide](https://github.com/Seckcey/plenipo/blob/main/docs/development/setup.md#3-ai-tools-claude-code-and-codex-phase-3-optional)).
If a Codex task fails with _"The '…' model is not supported when using Codex with a ChatGPT
account"_, the guide's notes show how to fix Codex's model setting.
