# v1.15.0 — GitHub Copilot, checked before every task (Phase 16, Wave 2)

**GitHub Copilot** joins Plenipo as its seventh AI tool. Before every task, Plenipo asks Copilot
how it is signed in and whether GitHub may charge for extra use, and runs the task only when
nothing can cost money. Cursor's agent was checked too, and waits for now. Plenipo by **8 West
Ventures, LLC**.

This is the second of four waves of Phase 16. It was built beside Phase 21 (the workspace).
Nothing you rely on changed how it works.

## Highlights

- **GitHub Copilot.** Install it with `winget install GitHub.Copilot`, then choose **Sign in** on
  its card: `copilot login` opens in a tab and finishes in your browser. If the GitHub CLI is
  already signed in, Copilot can use that sign-in too.
- **Checked before every task.** Copilot's card says **Copilot sign-in** or **GitHub CLI
  sign-in**. A token, a key, or a sign-in Plenipo does not recognize is never used.
- **Paid extra use stays off.** Plenipo checks every Copilot allowance before every task. If
  GitHub may charge once an allowance runs out, the card says so, in plain words, and no task runs
  until you give **AI Credits** a $0 budget with **Stop usage** on (github.com → Settings → Billing
  and licensing → Budgets and alerts) and choose **Check again**. With that set, GitHub refuses
  anything past your allowance, and Plenipo treats it as a usage limit.
- **Its models.** On the plan checked, Copilot offers only **Auto**, which picks the model itself.
  Who made it is not known, so its work plays safe in cross-company review. The card's Models tab
  shows what Copilot reports, and **Left of your plan** shows its allowances.
- **A card now says why its sign-in check refused work**, right under the sign-in, when the check
  gives a reason: for GitHub Copilot, what to change in GitHub. The Workers page says the same
  when a task is refused.

## Safer than before

- **A settings folder of its own.** Copilot runs with a settings folder Plenipo keeps in its app
  data, so none of your own Copilot settings, hooks, add-ons, or agents apply to Plenipo's tasks.
- **Text answers only.** Copilot's own tools are off, GitHub's own add-on server is off, and a
  folder's `AGENTS.md` files are not read. If one of its own tools runs anyway, or a model billed
  per use answers, Plenipo stops the task.
- **No updates in the middle of a task.** Copilot's own updates are off in Plenipo's tasks;
  **Update** on its card updates it between tasks.

## Known limits

- The check runs before each task, not during it. If paid extra use is turned on in GitHub while a
  task runs, that task finishes; the next one does not start.
- With only Auto on your plan, Copilot's work never counts as another company's in cross-company
  review.
- Copilot workers cannot read files, run programs, or open web pages.
- Copilot has no sign-out command: sign out inside Copilot (`/logout`), or with `gh auth logout`.
