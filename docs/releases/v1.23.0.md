# v1.23.0 — Linux (first look)

**Plenipo now runs on Linux.** This is a first look: it works, and the owner is still trying it
on a real Linux PC, so expect small fixes in the next few versions. The Mac comes next (Phase 23,
Wave 3). On Windows, nothing changes. Plenipo by **8 West Ventures, LLC**.

## Highlights

- **Two Linux downloads on this release page:**
  - **`Plenipo_1.23.0_amd64.deb`** for Ubuntu 22.04, 24.04, and 26.04, and Debian 12 or newer.
    Open it with your software installer, or run `sudo apt install ./Plenipo_1.23.0_amd64.deb`.
  - **`Plenipo_1.23.0_amd64.AppImage`** for most other Linux. Mark it as a program (right-click →
    Properties → "Allow executing", or `chmod +x`), then open it.
- **Updates.** The AppImage updates itself, checked with the same updater key as Windows. A copy
  installed from the `.deb` tells you when a new version is ready and opens this page to download
  it.
- **Your saved keys** live in your computer's password store (GNOME Keyring or KWallet), never in
  a file (ADR-153, saved keys on Linux). The `.deb` suggests GNOME Keyring if you have none.
- **Delete my Plenipo data**, in Settings → Info on Linux (and on a Mac, later). Removing an app on
  Linux never touches your home folder, so this button does it. It asks first, removes the keys
  Plenipo saved, deletes Plenipo's own folders, and quits.
- **The workers' browser** can be Microsoft Edge, Google Chrome, Chromium, or Brave. A Chromium
  from the Snap Store can't be used, and Settings says why.
- **The tray.** Plenipo sits in the tray on desktops that show one. Where the desktop has no tray
  (plain GNOME without its extension), the window stays open, and closing it quits Plenipo.

## For you, the owner

- **Try it on a Linux PC** (the Phase 23 check): install the `.deb`, sign in to Claude Code, run
  one Development goal with the same approvals as on Windows, restart the PC, and see that your
  keys are still saved. Tell Claude what you find; fixes go into the next version.
- **Record the sign-in answers on Linux**: each AI tool's real sign-in answers, the way they were
  recorded on Windows, so Plenipo reads them right on Linux too.
- On Windows, install this update as usual. Plenipo offers it by itself, or you can download it
  here.

## Good to know

- **Computer use works on X11, not yet on Wayland.** Ubuntu starts in Wayland. To use computer
  use, click the gear button when you sign in and choose "Ubuntu on Xorg". Under Wayland, Plenipo
  says so plainly and never takes a picture of part of the screen (ADR-154, computer use on
  Linux). Wayland support comes in Wave 4.
- **Start when you sign in** works on Linux too. It starts Plenipo in the tray, or with its window
  open where there is no tray.
- **Linux has no signing like Windows'.** The `.deb` names 8 West Ventures, LLC as its maker, the
  AppImage's updates carry 8 West's updater signature, and GitHub shows each file's SHA-256
  checksum on this page.
- **Every release now checks its Linux files** before publishing: the `.deb` installs, Plenipo and
  the AppImage start and keep running, and removing the `.deb` leaves your own data alone.
