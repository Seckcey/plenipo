# v1.23.0 — A live chat with each agent

**This release lets you chat with each agent and watch it work as it happens. Agents now save files
and run programs without asking you first, and orders and results travel along the chain of
command.** Plenipo by **8 West Ventures, LLC**.

## Highlights

- **A live chat with each agent.** Choose an agent on the Organization map and press **Chat**, or
  use Chat in its details panel or in the top bar. The **Chat** panel sits beside Terminal and
  Files, or opens in its own window. Each agent gets its own tab, and **Side by side** shows up to
  four chats at once.
- **Watch the work as it happens.** The answer appears word by word. A line says what the agent is
  doing now, with a timer ("Running a script · 2m 18s"), and says so when Claude's servers are busy
  and it tries again. Claude's thinking and each run of steps are one line you can open. A message
  you send while the agent works waits its turn, and **Stop** stops the work.
- **Agents save files and run programs.** **Settings → Safety** has three choices: **Light** (where
  Plenipo starts), **Careful**, and **Strict**, and says what each one means. VPs, Managers, and
  Supervisors start with **Everyday work**.
- **Find what an agent made.** Work that belongs to no project is saved in Plenipo's folder:
  Documents → Plenipo → your organization → the agent. Under each answer, **Files saved** lists the
  files and where they are, with **Open folder**.
- **The chain of command.** When you give an order straight to an agent lower down, the leads it
  skipped are told. When the work is done, the result is reported back up one level at a time, and
  each lead's chat shows it under **Chain of command**. An order for an on-call worker, such as a
  Developer, goes through its lead, who hands it on.

## For you, the owner

- Install this update on your PC. Plenipo offers it by itself (it checks GitHub once a day), or
  you can download it from this release.
- **On Light, agents act without asking you first.** A program or script an agent runs can do
  anything you can do on your PC, and Plenipo cannot see everything inside one. To be asked before
  a program that is not on your approved list runs, and before every PowerShell script, choose
  **Careful** in Settings → Safety. On **Strict**, agents only read.
- **A Supervisor still on Read only** moves to **Everyday work** once, unless you chose its
  permissions yourself. A choice you made stays as it is.

## Fixed

- **A program that ends at once** no longer keeps showing as "Running" on the AI tools page. Its
  end could arrive before Plenipo's own note that it had started.

## Good to know

- **Never allowed, whichever you choose:** reading or changing your secrets and the files on your
  blocked list, running the programs on your Never run list, and opening or changing files outside
  the agent's own folder with Plenipo's file tools. Sending work out, like pushing code to GitHub,
  still asks you first.
- **A lead in its team's project folder** reads there and hands each change to the worker who makes
  it, so each folder has one writer and your own saves never wait.
- **A lead hears its news once.** The next time you write to a lead, its agent gets a short note of
  what came back up to it.
- **Not yet:** AI tools that write answers only (Ollama, OpenRouter, direct keys, GitHub Copilot,
  and Antigravity) cannot save files or run programs; the chat says so when it applies. A link an
  agent wrote copies its address instead of opening.
