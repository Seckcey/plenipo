# v0.4.0 — Provider runtime adapters (Phase 3)

Plenipo can now run real AI workers: give an objective to **Claude Code** or **Codex** from the
new **Workers** view, using the command-line tools already signed in on your computer. The
Claude and Codex desktop apps do not need to be open.

## Highlights

- **Workers view.** Pick a runtime, give it an objective, and watch live activity. Claude Code
  streams its answer as it writes. Every turn ends with a normalized result showing the answer,
  token usage, and the reason if something went wrong.
- **Continue and cancel.** Send follow-ups in the same conversation (the provider session is
  resumed), cancel a running turn, or close the session.
- **Runtime diagnostics.** Runtimes → Agent runtimes shows each tool's installation, version,
  sign-in method, and capabilities, with **Re-check** and install/sign-in guidance.
- **Recorded in the Ledger.** Each turn is a task with its full activity trail, execution, and
  result. A turn that was running when Plenipo stopped is recorded as interrupted.

## Safety

- **Subscription sign-ins only.** Plenipo never asks for passwords or API keys. A tool signed in
  with an API key or through a third-party cloud is refused, and Claude Code is checked again
  during every turn. A usage limit never switches work to another provider.
- **No credentials passed on.** API-key environment variables are never given to the tools.
- **Read-only for now.** Claude Code runs with no tools, and Codex runs in its read-only sandbox,
  each in its own empty folder. File, shell, and network permissions arrive with Plenipo Guard
  (Phase 7).

## Install

Download `Plenipo_0.4.0_x64-setup.exe` below and run it. It is a per-user install with no admin
rights needed. The installer is not code-signed yet, so Windows SmartScreen may warn: choose
**More info → Run anyway**. Your existing Ledger is upgraded automatically, after a verified
backup of the previous version.

To use Workers, install and sign in to the tools (see the
[setup guide](https://github.com/Seckcey/plenipo/blob/main/docs/development/setup.md#3-agent-runtimes-phase-3-optional)):

```powershell
irm https://claude.ai/install.ps1 | iex    # Claude Code (native build)
claude auth login
npm install -g @openai/codex               # Codex (needs Node.js)
codex login                                # choose "Sign in with ChatGPT"
```
