# v1.18.1 — A key box on every AI tool card, and no spending cap needed

A fix to Phase 16's paid AI keys, found by the owner on Windows: the place to add a key was hard
to find, and a key needed a spending cap first. Plenipo by **8 West Ventures, LLC**.

## Changes

- **A key box on every AI tool card.** On the AI tools page, each card you sign in to now has an
  **Or pay per use with your own key** box:
  - Claude Code takes your **Anthropic** key, Codex your **OpenAI** key, Grok your **xAI** key,
    Kimi your **Moonshot AI** key, and Antigravity your **Google** key.
  - Ollama and GitHub Copilot take an **OpenRouter** key, which reaches the same kinds of models,
    and many more.
  - It is the same key as on that company's own card, kept once in Windows Credential Manager.
    Work on it is priced and listed under Spending caps; the AI tool you sign in to keeps using
    your subscription.
- **The AI tools paid per use have their own part of the page,** **Paid per use with your key**,
  with a button at the top that goes there.
- **No spending cap is needed.** You can add a key, and paid work runs, without a cap. Where you
  add a key, Plenipo says you can set a spending limit in Settings → Spending caps if you want; it
  is not required. Without one, paid work has no dollar limit, and every paid task is still priced
  and listed. Caps you set still hold, and the business's cap can now be removed while a key is
  saved.
- **Words that no longer fit were changed** on the AI tools page, Settings → Switches, Spending
  caps, AI models, and About: Plenipo no longer says it "never asks for API keys", that "no paid
  key works without the business's cap", or "Pay-per-use API billing: Off". An AI tool signed in
  with its own API key outside Plenipo is still not used, and the words now say why: its costs
  would skip your spending caps.

Paid AI keys still work only while **Settings → Switches → Let workers use paid AI keys** is on,
and only for positions you list them for. Nothing else changed. This update does not change the
Ledger.

## Install

Download `Plenipo_1.18.1_x64-setup.exe` below and run it, or let Plenipo install the update. It is
a per-user install with no admin rights needed, signed as **8 West Ventures, LLC**.
