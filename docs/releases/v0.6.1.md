# v0.6.1 — Short messages between agents

Team tasks are much faster. Agents now write each other short notes instead of long briefs, so
a supervisor's round trip with its team takes a fraction of the time: in the owner's first
test, a supervisor's team task finished about 90% faster.

## Changes

- **Short messages between agents.** A request says what to do and what to send back, in a few
  sentences. A reply carries just the result; for code, the code and a sentence or two. Only
  what the next agent needs is passed along, not the whole conversation.
- **Limits back this up.** A request is at most 1,000 characters; a longer one is sent back to
  the agent with "keep it short". A reply longer than 8 KB is cut short before it's passed on,
  and the full reply stays in the record.
- **Clearer Codex errors.** Codex's error sentence is shown even when Codex wraps it in other
  text, instead of the raw code around it.

## Install

Download `Plenipo_0.6.1_x64-setup.exe` below and run it. It is a per-user install with no admin
rights needed. The installer is not code-signed yet, so Windows SmartScreen may warn: choose
**More info → Run anyway**. This update does not change the Ledger.

If a Codex task fails with _"The '…' model is not supported when using Codex with a ChatGPT
account"_, the
[setup guide's notes](https://github.com/Seckcey/plenipo/blob/main/docs/development/setup.md#3-ai-tools-claude-code-and-codex-phase-3-optional)
show how to fix Codex's model setting, or you can choose a model for that position in Plenipo.
