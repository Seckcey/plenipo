# v0.7.0 — Which AI model each role gets (Phase 6)

You now decide which AI model each role's workers use, and how hard it thinks. Change a role's
model choices in Settings and its next worker follows — no instructions to rewrite — and every
worker says why it got its model.

## Highlights

- **Settings → AI models.** For every role, the model its next worker would get and why. Give a
  role its model choices: a first choice and backups in order, what the model must be able to do
  (see images, make images, use a computer), a minimum context size, AI companies it never uses,
  and, for reviewers, a model from a different AI company than the work it checks.
- **Pick models from a menu.** Wherever you choose a model, the menu lists the AI tool's default,
  then the models the AI tool offers itself — Claude Code: Fable, Opus, Sonnet, Haiku; Codex:
  GPT-6-Astra, GPT-6-Sol, GPT-6-Luna and its older models — then your models and the models seen
  in use. **Type another name…** is there for anything else.
- **Effort.** Set how hard a model thinks (low to max for Claude Code, low to ultra for Codex),
  per model and per role. The menus offer only the levels the chosen model takes (Haiku has
  none). A conversation keeps its effort for every turn.
- **Automatic positions.** New positions follow their role's model choices ("Auto · Claude Code"
  on the map). You can still fix a position to one AI tool and model. Positions from earlier
  versions keep the AI tool they had.
- **Always explained.** The details panel shows "Why this AI model" with every model considered;
  each worker and the Activity trail say why it got its model ("Sonnet (Claude Code) is Senior
  Developer's first choice and is ready. It runs at high effort.").
- **Usage limits.** When an AI tool reaches its usage limit, work waits for it to reset instead
  of moving to another AI company, unless you choose "use the next choice". **Try again now**
  lifts a limit early. Pay-per-use API billing stays off.

## Install

Download `Plenipo_0.7.0_x64-setup.exe` below and run it. It is a per-user install with no admin
rights needed. The installer is not code-signed yet, so Windows SmartScreen may warn: choose
**More info → Run anyway**.

This update upgrades the Ledger (schema 5, which stores each conversation's effort). Plenipo backs
the Ledger up before upgrading it.

## Known limits

- The models each menu lists are the ones Claude Code 2.1.283 and Codex 0.157.1 offer. A model a
  newer CLI adds shows up under "Seen in use" once a worker runs it, or can be typed.
- Plenipo cannot ask an AI tool what a model can do; mark "sees images" and the like yourself.
  The Designer role has no model until one is marked as able to see and make images.
