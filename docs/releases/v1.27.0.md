# v1.27.0 — Your organization's folder, a tree of your workers, and a straight line to each agent

**This release fixes the Stop buttons, gives each organization a folder of its own, turns the
Workers tab into a tree you can open, and lets you talk to an agent without anyone in between.**
Plenipo by **8 West Ventures, LLC**.

## Highlights

- **Stop works.** The Stop button in a chat now ends the agent's turn, and **Stop all** ends every
  running agent. If an AI tool goes quiet for a few minutes, the chat says so, and after ten
  minutes Plenipo stops it for you. A stopped turn says "Stopped".
- **Your organization has a folder.** A new organization gets a folder with a place for each
  department, each project, and each agent's scratch pad. The **Files** tab opens that folder.
  Plenipo never opens a file that OneDrive keeps only online just to list it, and it will not use
  a folder that is not safe to use (for example a system folder or a drive's top folder).
- **The Workers tab is a tree.** Open a department, then a project, then a worker, and read that
  worker's chat. It streams as the AI tool writes. Chats between agents, such as a supervisor and
  the worker it handed work to, show in the chats of both.
- **Talking to an agent is direct.** What you type in an agent's chat goes straight to that agent.
  The Liaison is now only for work that passes between agents.
- **What a task cost.** After a task finishes, its page shows the tokens used (read, reused, and
  written) and, on paid keys, the money. On a subscription it shows tokens only.
- **Edit a project.** Projects now have an **Edit** button on the Projects page and on the
  project's own page.
- **A worker's chat after the work is done.** Opening a worker's chat later still shows the whole
  conversation.
- **GitHub sign-in (not turned on yet).** Settings → Connections has a GitHub sign-in that can
  list your repositories. It stays unavailable in this release until 8 West's GitHub app is
  registered, and Plenipo says so on the screen.

## Fixed

- A chat's Stop button, and Stop all, now end the agent's turn.
- An AI tool that froze while "writing" is noticed, and a note shows in its chat.
- Live text in a chat is hidden as whole words, so a secret is never shown a letter at a time.

## For you, the owner

- Install this update on your PC. Plenipo offers it by itself (it checks GitHub once a day), or
  you can download it from this release.
- To use the organization folder, make a new organization or open the Files tab. If the folder is
  in OneDrive, Plenipo asks you to turn on **Always keep on this device** for it in your OneDrive
  settings.

## Good to know

- The decisions are ADR-204 (a read-only GitHub connection), ADR-205 (the organization folder), and
  ADR-208 (talking to an agent is direct); all three are still waiting for the owner's OK.
- Chats that began before this update keep their older instructions to the AI tool until the team
  or its limits change.
- Setting up a project with its own folder, picking a repository from a list, and moving files to
  your computer come in the next release.
