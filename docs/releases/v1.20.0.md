# v1.20.0 — Getting ready for Mac and Linux

**This release starts Phase 23, Plenipo for Mac and Linux.** There is no Mac or Linux download yet:
this is the groundwork underneath, built and tested on all three systems. On Windows you will
notice almost nothing, and a few fixes make Plenipo steadier everywhere. Plenipo by **8 West
Ventures, LLC**.

## Highlights

- **Plenipo is now built and tested on a Mac for every change,** as it already was on Windows and
  Linux. Trial Mac and Linux downloads were built too, to check what they will look like.
- **Guard is ready for a Mac and Linux.** When Plenipo cannot check which program is asking to use
  a worker's tools, it now says no (ADR-156). On a Mac it can now check. Plenipo never runs a
  terminal or its browser as the Mac's or Linux's all-powerful user (root). And on a Mac and Linux,
  where `Deploy` and `deploy` can be two different programs, an approval names a program exactly.
- **On a Mac and Linux, a worker's programs stop when Plenipo does,** even if Plenipo crashes. A
  small helper, the keeper, makes sure of it (ADR-157). Windows always did this.
- **On Linux, saved keys survive a restart.** They now live in the desktop's own password store,
  GNOME Keyring or KWallet (ADR-153).
- **On a Mac and Linux, Plenipo finds AI tools** installed with Homebrew, npm, nvm, Volta, and the
  like, even when it is opened from the Dock or a menu.

## For you, the owner

- Install this update on your PC. Plenipo offers it by itself (it checks GitHub once a day), or
  you can download it from this release.
- Nothing to check by hand for this one: Windows works as before.

## Good to know

- **Fixes for everyone:** Plenipo could lose track of a finished program whose output closed
  slowly, so the program was never marked finished. And a program found through PATH is now
  counted as the project's own file (which never gets a saved secret) whenever its real location,
  after shortcuts and links, is inside the project.
- **New installs block a few more risky programs** that only exist on a Mac or Linux, such as
  AppleScript (`osascript`) and the Mac's Keychain tool (`security`). Your own lists do not change.
- **Activity says it plainly** when Plenipo refused a tool call because it could not check which
  program sent it.
- The plan, every decision, and what is left are in the
  [Phase 23 checklist](../phases/phase-23-checklist.md). Community (Phase 24) is being built beside
  it (ADR-160).
