## 3. Defects found and fixed during Phase 2

| Found by          | Problem                                                                                                                                                                                     | Fix                                                                                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Windows CI        | With several connections writing at once, one writer gave up with `database is locked` after SQLite's 5 s busy timeout (SQLite's lock hand-off is not fair; Windows disk flushes are slow). | Writes retry taking the write lock with backoff for up to 60 s; opening an up-to-date ledger no longer needs the write lock. Regression test holds the lock 6.5 s. |
| Linux CI          | New clippy lint in Rust 1.98 (CI) that local 1.94 didn't have.                                                                                                                              | Fixed the loop; **pinned Rust to 1.98** in `rust-toolchain.toml` so local and CI always match (Phase 0 risk R5).                                                   |
| CI E2E            | Test read the trail element-by-element while it re-rendered (stale element).                                                                                                                | Atomic in-page snapshot; waits for exact expected content.                                                                                                         |
| Screenshot review | Global sequence numbers looked like gaps in a task's trail; badges stretched on long names.                                                                                                 | Per-task step numbers (global sequence in tooltip); badge sizing.                                                                                                  |
| Doc audit         | Several Phase 1 doc edits had silently not applied to formatter-padded tables.                                                                                                              | Restored: full command/event reference, `pnpm e2e`, test-only env vars, directory table.                                                                           |

## 5. Security notes

- The UI never supplies file paths: backup/export locations are chosen by Core; a path passed
  from the webview is ignored (IPC test).
- Synthetic-task controls act **only** on tasks created as synthetic; real tasks cannot be
  changed from Diagnostics (IPC test).
- Events are append-only at the database level; history cannot be rewritten through the API.
- No output, environment values, or secrets are stored; payload redaction is Phase 7.
