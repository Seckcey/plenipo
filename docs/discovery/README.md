# Repository presentation assets

The README uses the approved Plenipo/Pip branding, copied without changing the original
files from the supplied `assets/logos` kit. The source kit remains owned by the branding work.

| File                                     | Source and meaning                                                                                                                 |
| ---------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `assets/plenipo-horizontal-on-light.png` | Exact approved transparent PNG for light backgrounds                                                                               |
| `assets/plenipo-horizontal-on-dark.png`  | Exact approved transparent PNG for dark backgrounds                                                                                |
| `assets/organization-v1.7.0.png`         | Exact copy of `docs/phases/evidence/phase-12a/page-organization-light.png`, a real app acceptance capture with synthetic test data |
| `assets/social-preview.svg`              | Native 1280 × 640 layout containing the unchanged approved light-background logo geometry and embedded Pip artwork                 |
| `assets/social-preview.png`              | PNG export of that native layout, with an opaque background for consistent sharing                                                 |

The logo is hybrid artwork: outlined vector lettering plus embedded raster Pip, not a fully
vector mascot. No new mascot was generated, and no product screenshot was redrawn or generated.
The screenshot shows **v1.7.0 development**; other releases may look a little different.

The social SVG is the self-contained, editable master. To rebuild the PNG, open it in a vector
editor and export at 1280 × 640 with its solid background. Keep the PNG under 1 MB.
The README selects light/dark logos with a `picture` element. Keep a meaningful fallback `img`
and descriptive alt text. Check both variants on GitHub when updating the artwork.
