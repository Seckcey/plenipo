# Get help with Plenipo

Start with the [FAQ](docs/faq.md) and [Windows setup guide](docs/development/setup.md).
Download installers only from [GitHub Releases](https://github.com/Seckcey/plenipo/releases/latest).

| You need                           | Where to go                                                                                        |
| ---------------------------------- | -------------------------------------------------------------------------------------------------- |
| Setup help, a question, or an idea | [GitHub Discussions](https://github.com/Seckcey/plenipo/discussions)                               |
| A reproducible bug                 | [Bug report form](https://github.com/Seckcey/plenipo/issues/new?template=bug_report.yml)           |
| A proposed feature                 | [Feature request form](https://github.com/Seckcey/plenipo/issues/new?template=feature_request.yml) |
| A security concern                 | Read [SECURITY.md](SECURITY.md) before sharing any details                                         |
| A contribution                     | [Contributing guide](CONTRIBUTING.md)                                                              |

## Make a report easy to reproduce

Include your Plenipo version, Windows version, the AI tool and its version if relevant, the
smallest steps that reproduce the problem, and what you expected versus what happened. Say
whether you used a published installer or built a particular commit. Include a small sanitized
screenshot or log excerpt if it helps.

Do not upload passwords, tokens, API keys, credential files, private project contents, customer
data, or an entire activity database. Review logs and screenshots before posting: automatic
redaction may not recognize every secret. Replace personal folder names and server addresses
with placeholders.

## When an AI tool is not ready

Open **AI tools**, choose **Re-check**, and read the card's explanation. Confirm the tool is
installed and signed in with its supported account, then follow the provider-specific section
of the [setup guide](docs/development/setup.md#3-ai-tools-claude-code-codex-grok-kimi-ollama-antigravity-and-github-copilot-optional).
Provider outages, subscription access, and usage limits need to be resolved with that provider.

Support is provided through the repository. Response times are not guaranteed.

## Privacy and legal requests

Read the [privacy statement](apps/website/legal/privacy.md) and
[terms of service](apps/website/legal/terms.md). Send private privacy or legal requests to
[admin@8westventures.com](mailto:admin@8westventures.com). Do not include sensitive details in
public GitHub posts.
